## About the Project

This repository contains 15 Python practical programs developed as part of the Object Oriented Programming Using Python subject. The programs demonstrate fundamental Python concepts, mathematical computations, string manipulation, data structures, file handling, exception handling, classes, objects, and inheritance.

The objective of this repository is to develop practical programming skills and understand the core concepts of Python through hands-on implementation.

## How to Run the Programs

**Step 1:** Install Python 3 on your computer.

**Step 2:** Clone this repository.

```bash
git clone https://github.com/deepshikha-1912/python-programs.git
```

**Step 3:** Navigate to the project directory.

```bash
cd python-programs
```

**Step 4:** Run any practical using Python.

```bash
python practical01.py
```

Replace `practical01.py` with the filename of the practical you want to execute. If required by your system, use `python3` instead of `python`.
